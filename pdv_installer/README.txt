OBRIGADO POR INSTALAR O PDV SUPERMERCADO!

----------------------------------------------------------------
PRIMEIRO USO
----------------------------------------------------------------
1. Abra o programa pelo atalho na área de trabalho ou menu iniciar
2. No primeiro uso, será criado o banco de dados automaticamente
3. Login padrão de gerente:
   Usuário: admin
   Senha:   admin
4. IMPORTANTE: Altere a senha do admin imediatamente!

----------------------------------------------------------------
ATALHOS DE TECLADO
----------------------------------------------------------------
F1   - Ajuda
F2   - Cadastro de produtos
F3   - Cadastro de clientes
F4   - Abrir caixa
F5   - Fechar caixa
F12  - Finalizar venda

----------------------------------------------------------------
ONDE FICAM OS DADOS
----------------------------------------------------------------
Banco de dados, backups e logs ficam em:
C:\ProgramData\PDV Supermercado\

IMPORTANTE: Faça backups regulares pelo menu Utilitários > Backup!
